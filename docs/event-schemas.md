# Event Schemas

JSON Schema files are in `schemas/`.

| File | Description |
|------|-------------|
| `common_event_envelope.schema.json` | Wrapper for all events |
| `verify_request.schema.json` | Inbound verification request |
| `verify_result.schema.json` | Outbound verification result |
| `inventory_snapshot.schema.json` | F5 inventory snapshot |
