# Source Refresh Guidance

When refreshing context about this codebase:

1. Read `IMPLEMENTATION_PROGRESS.md` to know what is and is not implemented.
2. Read `AGENTS.md` for execution guardrails.
3. Read `app/contracts/` to understand all I/O schemas.
4. Read `app/domain/reason_codes.py` for verdict codes.
5. Read `app/config/settings.py` for all configuration keys.
6. Run `pytest tests/unit/` to verify scaffold integrity.
